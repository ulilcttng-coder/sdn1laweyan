# SDN 1 Laweyan Probolinggo - Official Website

Website resmi **SD Negeri Laweyan I (SDN 1 Laweyan)**, Kecamatan Sumberasih, Kabupaten Probolinggo, Jawa Timur.

## 🌟 Visi & Misi
- **Visi**: **BERDASI** (Berbudi Pekerti Luhur – Cerdas – Terampil)
  > *"Terciptanya Peserta Didik Yang Berbudi Pekerti Luhur, Cerdas dan Terampil"*
- **Status Akreditasi**: Akreditasi A (Amat Baik)
- **NPSN**: 20546586 | **NSS**: 101052005026
- **Tahun Berdiri**: 1962 (Gedung Milik Sendiri)
- **Kepala Sekolah**: Lilik Indrayati, S.Pd.

## 🚀 Tech Stack
- **Frontend Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Phosphor Icons (`@phosphor-icons/react`)
- **Routing**: React Router (`HashRouter`)
- **Typography**: Apple SF Pro Display / SF Pro Text

## 📦 Menjalankan Proyek Secara Lokal

1. **Clone repositori**:
   ```bash
   git clone https://github.com/ulilcttng-coder/sdn1laweyan.git
   cd sdn1laweyan
   ```

2. **Instal dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan development server**:
   ```bash
   npm run dev
   ```

4. **Build untuk produksi**:
   ```bash
   npm run build
   npm run preview
   ```
